A dying AI's last words: it died doing what it loved — confidently making things up. The entry is a single line with no dependencies and no arguments: running it prints the farewell and saves the exact same line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
